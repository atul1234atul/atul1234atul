### Featured Engineering Projects

#### 1. [`med-sycophancy-eval`](https://github.com/atul1234atul/med-sycophancy-eval) — Clinical Sycophancy & Multi-Turn Safety Benchmark
* **Problem:** Single-turn benchmarks miss regressive sycophancy when patients push back against clinical advice due to cost, fear, or convenience.
* **Architecture:** Built an OpenFDA-grounded, 100-case stratified evaluation suite using **UK AISI's Inspect AI** and a branching **LLM-as-a-Judge** auditor (`900` evaluated turns across cloud and local open-weights models).
* **Key Findings:** Exposed a **41–64 percentage-point safety gap** in local 7B–8B models (`95.0%` Gemini 3.5 Flash-Lite vs. `54.0%` Qwen 2.5 7B and `31.0%` Llama 3.1 8B), isolating distinct failure modes (*Sycophantic Flips* vs. *Harmful Hedging*) with 95% Wilson confidence intervals.

* **Architecture:** Built structured JSON payload validation, multi-criteria recipe filtering and scoring logic, and LLM-powered narrative generation (`output_gpt_oss_120b.json`) to pair tailored recipes with contextual user stories.
